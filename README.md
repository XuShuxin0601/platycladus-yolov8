# Platycladus orientalis Detection Dataset and Related Materials

This repository provides a partial sample dataset and related materials associated with the manuscript:

**A Study on Urban *Platycladus orientalis* Species Identification Using an Enhanced YOLO Model and High-Resolution Satellite Imagery**

DOI: 10.1109/JSTARS.2026.3689021

## Overview

This repository is intended to provide representative sample data and related materials for illustrating the data format, annotation structure, and experimental workflow used in the study. The current version does not contain the complete dataset used in the manuscript.

The released files are provided for academic reference and reproducibility support. They are not intended to represent the full training, validation, or inference dataset described in the paper.

## Current Release

At the current stage, this repository includes only a partial sample dataset and selected related materials, such as:

- sample image tiles;
- corresponding annotation files;
- example dataset configuration files;
- sample file structure;
- related documentation.

The full dataset and complete model files are still being organized and curated. We plan to update this repository progressively after the data and model files have been further checked, standardized, and prepared for public release.

## Data Availability

A partial sample dataset is provided in this repository. The complete dataset is not publicly released at this stage due to ongoing data curation and data-use considerations related to high-resolution commercial satellite imagery.

After further organization and verification, additional data samples, trained model files, and related experimental materials will be uploaded to this repository when available and permitted.

For further information, please contact the corresponding author upon reasonable request.
